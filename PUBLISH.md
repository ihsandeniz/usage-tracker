# Release checklist

The repo is already public: **github.com/ihsandeniz/usage-tracker**.

> **Layout note (2026-08-11).** This directory *is* the public repo — there is no second copy
> and no `rsync` step any more. `git remote -v` here points at `origin`, and the surrounding
> vault ignores this path. Whatever you run and test here is exactly what ships.
>
> `CLAUDE.md` is listed in `.gitignore`: it holds working notes that must not reach a public
> repo. Do not remove that line.

## Before every release

```bash
./install.sh            # should generate config + print snippets, no errors
./start.sh &            # server on :8770
sleep 2
curl -s 127.0.0.1:8770/v1/usage | jq .schema     # → "usage/v1"
./surface/waybar-usage.sh | jq .text             # → "◐ NN%"  (NOT empty)
kill %1
grep -rn "/home/" . --include='*.py' --include='*.js' --include='*.sh' || echo "no hardcoded home paths ✓"

# systemd service template verification
sed "s|@@ROOT@@|$PWD|g; s|@@PYTHON@@|$(command -v python3)|g" \
    packaging/usage-tracker.service.in > /tmp/test-usage-tracker.service
grep -q "@@ROOT@@\|@@PYTHON@@" /tmp/test-usage-tracker.service && \
  { echo "❌ FAIL: systemd template has unsubstituted placeholders"; exit 1; } || \
  echo "✓ systemd service template validates"
```

All of these must pass. Empty feeder output = a regression in the jq guards — do not ship.
Unsubstituted placeholders in the service file — do not ship.

## Nothing machine-specific gets committed

`.gitignore` already excludes the files that are generated per machine rather than authored:

| File | Why it is ignored |
|---|---|
| `surface/surface.conf` | generated by `./install.sh` for this machine |
| `usage_calib.json` | your calibration |
| `view_config.json` | which cards you hid |
| `CLAUDE.md` | working notes, vault-only |

Check with `git status --short` before tagging — it should be empty.

## Cutting a release

```bash
git tag -a vX.Y.Z -m "..."     # must match VERSION in server.py
git push origin main --tags
gh release create vX.Y.Z --generate-notes
```
